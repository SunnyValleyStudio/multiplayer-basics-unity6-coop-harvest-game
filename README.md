## 🎮 About This Project

This project is designed to teach Unity multiplayer game development fundamentals through 
a practical, hands-on approach. Perfect for developers who want to learn Netcode for GameObjects 
and understand core multiplayer concepts.

## 📚 What You'll Learn

- Setting up Netcode for GameObjects in Unity 6
- Network spawning and object synchronization
- Player movement with NetworkTransform
- ServerRpc and ClientRpc patterns
- NetworkVariables for shared state
- Tool and interaction systems
- Collection and delivery mechanics
- How to create a gameplay mechanic that is synchronized over the network

## 🛠️ Built With

- Unity 6.3+
- Netcode for GameObjects 2.8+
- UI Toolkit
- New Input System
